## Це сховище

Це форк [QymCAD](https://github.com/QymIs-Tech/QymCAD). Графічна програма тут та сама. У цьому форку додано API, який веде один документ без цієї програми. Термінальна програма є для того, щоб клієнт MCP викликав це API.

Це API — бібліотека `qymcad-drive`. Сесія тримає документ і геометричне ядро. Після кожної зміни вона перебудовує модель і повертає дерево: деталі, ескізи, стрічку операцій, тіла, спряження та ступені свободи. Через сесію програма відкриває і зберігає файл QymCAD, а також читає і записує STEP та STL. Ескіз на координатній площині стає тілом видавлюванням, обертанням, протягуванням уздовж шляху або лофтом. Кубоїд, циліндр, сферу, конус, тор або призму можна поставити одразу. На готовому тілі сесія знімає фаску і скруглення, будує оболонку й отвір, об'єднує тіла або віднімає одне від іншого, повторює тіло в ряд або по колу, віддзеркалює його і розсікає. Грані того самого тіла можна нахилити, зрушити, змістити, видалити або замінити. Деталі можна поставити у збірку і зв'язати спряженнями. Розмір може бути виразом, а останній крок можна скасувати.

Термінальна програма `qymcad-mcp` викликає те саме API. Вона говорить MCP через стандартне введення та виведення, і кожен інструмент виконує один метод. Запустити її може будь-яка програма, яка говорить MCP. Коли треба показати збережений файл, відкривається нова копія графічної програми, а модель, яка вже відкрита, лишається на місці.

Ліцензія — текст у файлі [LICENSE](LICENSE), GNU AGPL-3.0-or-later, та сама, що й у QymCAD. Інших умов цей форк не додає. Готові пакети QymCAD цього API і термінальної програми поки не містять. І те, і те є в цьому сховищі.

### Підключення в IDE

Термінальну програму збирають із цього сховища, з тими самими шляхами до OCCT 7.9.3, що й у розділі [Збирання з вихідного коду](#збирання-з-вихідного-коду):

```bash
cargo build --release --locked --bin qymcad-mcp
```

Програма лежить у `target/release/qymcad-mcp`. В IDE додають локальний сервер MCP. Команда — шлях до цієї програми. IDE говорить із нею через стандартне введення та виведення. Адреси і порта у сервера немає.

```json
{
  "mcpServers": {
    "qymcad": {
      "command": "/абсолютний/шлях/qymcad-mcp",
      "env": {
        "LD_LIBRARY_PATH": "/абсолютний/шлях/occt/lib",
        "QYMCAD_GUI": "/абсолютний/шлях/qymcad"
      }
    }
  }
}
```

Приклад вище записано для Linux. `LD_LIBRARY_PATH` називає каталог `lib` зібраного OCCT. Бібліотеки ядра завантажують одна одну, і шляху всередині файла програми їм недостатньо. `QYMCAD_GUI` — це графічна програма. Вона потрібна, коли показують збережений файл. У Windows у тому самому полі `env` каталог `lib` ставлять у `PATH`, а `LD_LIBRARY_PATH` не задають.

## Що це

QymCAD — настільний САПР для механічних деталей та збірок: корпусів, кронштейнів, механізмів,
друкованих та фрезерованих виробів.

Ескіз перетворюється на тіло видавлюванням, обертанням або замітанням (sweep); тіло доповнюється отворами,
скругленнями, оболонкою, масивами. Деталі збираються у вузол з'єднаннями — обертальними, повзунами,
жорсткими. Модель параметрична: зміна розміру в будь-якій операції перебудовує все, що розташоване
нижче за шкалою часу (timeline), включно зі збіркою.

Геометрія точна, об'ємна (B-rep) на ядрі [OpenCASCADE](https://dev.opencascade.org/) — тому самому, на
якому працює FreeCAD. Звідси точні поверхні замість полігональних сіток, коректні скруглення та обмін
через STEP з іншими САПР.

Інтерфейс доступний українською, англійською, казахською та російською мовами.

## Стан

Версія для розробки. Програма працює та придатна для реальних деталей, але оновлюється щодня.

- **Формат документа змінюється без зворотної сумісності.** Файл, збережений у попередній версії, може
  не відкритися. Для таких файлів є скрипт `convert_qcad.py` (див. нижче).
- **Модуль ЧПК (CAM) не працює.** У налаштуваннях є прапорець «Вкладка „Обробка“ (CAM)», але це заділ
  на майбутнє: частина коду залишилася від попередньої версії та не підтримується. Модуль повернеться
  у стабільній альфі.
- **Збірку для macOS підписано не Apple.** Вона підписана й цілісна, але сертифікатом, який видала не Apple,
  тому під час першого запуску macOS повідомляє, що не може перевірити програму, і не відкриває її.
  Дозволити потрібно один раз, кнопкою «Усе одно відкрити» в Системних параметрах -> Приватність і безпека;
  кроки — в інструкції поруч із програмою.

## Можливості

**Ескіз.** Лінії, дуги, кола, еліпси, сплайни, багатокутники, пази, текст. Зв'язки та розміри
вирішуються спільно; розміри параметричні (`w/2`, `sin(a)`). Є допоміжна геометрія та
проєкція ребер тіла в ескіз.

**Деталь.** Видавлювання, обертання, замітання (sweep), лофт, скруглення (зокрема змінного радіуса за
вершинами), фаска, оболонка, ухил, отвори (прості, цекування, зенкування), потовщення, латка,
зшивання, обрізання, поділ граней і тіла, копіювання та штовхання грані, лінійні й кругові масиви,
дзеркало, булеві операції. Є примітиви: паралелепіпед, циліндр, сфера, конус, тор, призма.
Різьба будується справжнім гвинтовим профілем зі збігами.

**Збірка.** Деталі й підзбірки, з'єднання (жорстке, обертальне, повзун, циліндричне, плоске,
кульове, штифт у пазу, паралельність), обмеження та приводи, ступені вільності, перевірка
інтерференції (перетинів). Ескіз можна будувати на грані сусідньої деталі як асоціативне посилання:
зміна сусідньої деталі автоматично перебудовує залежну.

**Обмін.** STEP (імпорт та експорт), STL (імпорт та експорт), DXF і SVG (імпорт та експорт
ескізів). Експортувати можна як увесь проєкт, так і окрему деталь чи підзбірку з дерева побудови.

## Встановлення

Збірки розміщені у розділі [Releases](../../releases). Додаткові бібліотеки не потрібні: OpenCASCADE та
залежності вже запаковані всередині.

**Windows 10/11 x64** — `qymcad-win64.zip`. Розархівувати в будь-яке місце та запустити `qymcad.exe`.

**Linux** — `qymcad-*.AppImage`, один файл. Потребує glibc 2.35 або новішої: Ubuntu 22.04+,
Debian 12+, Fedora 36+, Arch.

```bash
chmod +x qymcad-*.AppImage
./qymcad-*.AppImage
```

**macOS 12+** — для Apple Silicon (M1 і новіші) `qymcad-*-macos-arm64.dmg`, для Intel
`qymcad-*-macos-x86_64.dmg`. Відкрийте образ диска та перетягніть QymCAD у «Програми». Перший запуск буде один
раз відхилено, бо збірку підписано не Apple: натисніть «Усе одно відкрити» в Системних параметрах ->
Приватність і безпека. `ПРОЧИТАЙ.txt` поруч із програмою описує це покроково.

## Довідка

Вбудована довідка відкривається клавішею **F1**. Ілюстровані статті розташовані в [`docs/help`](docs/help).

## Файли проєкту

Документ зберігається як `.qcad`. Формат змінюється напряму, без шару сумісності; документи
попередніх версій перетворюються окремим скриптом:

```bash
python3 convert_qcad.py part.qcad    # оновлює файл на місці, поруч залишає part.qcad.bak
```

Скрипт переводить документ будь-якої попередньої версії до поточної за один прохід і є ідемпотентним.

## Збирання з вихідного коду
