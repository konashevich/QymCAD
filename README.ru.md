## Этот репозиторий

Это форк [QymCAD](https://github.com/QymIs-Tech/QymCAD). Графическое приложение здесь то же самое. В этом форке добавлено API, которое ведёт один документ без этого приложения. Терминальная программа есть для того, чтобы клиент MCP вызывал это API.

Это API — библиотека `qymcad-drive`. Сессия держит документ и геометрическое ядро. После каждого изменения она перестраивает модель и возвращает дерево: детали, эскизы, ленту операций, тела, сопряжения и степени свободы. Через сессию программа открывает и сохраняет файл QymCAD, а также читает и записывает STEP и STL. Эскиз на координатной плоскости становится телом выдавливанием, вращением, протягиванием вдоль пути или лофтом. Кубоид, цилиндр, сферу, конус, тор или призму можно поставить сразу. На готовом теле сессия снимает фаску и скругление, строит оболочку и отверстие, объединяет тела или вычитает одно из другого, размножает тело в ряд или по кругу, отражает его и рассекает. Грани того же тела можно наклонить, сдвинуть, сместить, удалить или заменить. Детали можно поставить в сборку и связать сопряжениями. Размер может быть выражением, а последний шаг можно отменить.

Терминальная программа `qymcad-mcp` вызывает то же API. Она говорит на MCP через стандартный ввод и вывод, и каждый инструмент выполняет один метод. Запустить её может любая программа, которая говорит на MCP. Когда нужно показать сохранённый файл, открывается новая копия графического приложения, а модель, которая уже открыта, остаётся на месте.

Лицензия — текст в файле [LICENSE](LICENSE), GNU AGPL-3.0-or-later, та же, что у QymCAD. Других условий этот форк не добавляет. Готовые пакеты QymCAD этого API и терминальной программы пока не содержат. И то и другое есть в этом репозитории.

### Подключение в IDE

Терминальную программу собирают из этого репозитория, с теми же путями к OCCT 7.9.3, что и в разделе [Сборка из исходников](#сборка-из-исходников):

```bash
cargo build --release --locked --bin qymcad-mcp
```

Программа лежит в `target/release/qymcad-mcp`. В IDE добавляют локальный сервер MCP. Команда — путь к этой программе. IDE говорит с ней через стандартный ввод и вывод. Адреса и порта у сервера нет.

```json
{
  "mcpServers": {
    "qymcad": {
      "command": "/абсолютный/путь/qymcad-mcp",
      "env": {
        "LD_LIBRARY_PATH": "/абсолютный/путь/occt/lib",
        "QYMCAD_GUI": "/абсолютный/путь/qymcad"
      }
    }
  }
}
```

Пример выше записан для Linux. `LD_LIBRARY_PATH` называет каталог `lib` собранного OCCT. Библиотеки ядра загружают друг друга, и пути внутри файла программы им недостаточно. `QYMCAD_GUI` — это графическое приложение. Оно нужно, когда показывают сохранённый файл. В Windows в том же поле `env` каталог `lib` ставят в `PATH`, а `LD_LIBRARY_PATH` не задают.

## Что это

QymCAD — настольный САПР для механических деталей и сборок: корпусов, кронштейнов, механизмов,
печатных и фрезерованных изделий.

Эскиз превращается в тело выдавливанием, оборотом или sweep'ом; тело дополняется отверстиями,
скруглениями, оболочкой, массивами. Детали собираются в узел сопряжениями — вращательными, ползунами,
жёсткими. Модель параметрическая: изменение размера в любой операции перестраивает всё, что стоит
ниже по ленте, включая сборку.

Геометрия точная, объёмная (B-rep) на ядре [OpenCASCADE](https://dev.opencascade.org/) — том же, на
котором работает FreeCAD. Отсюда точные поверхности вместо сеток, корректные скругления и обмен
через STEP с другими САПР.

Интерфейс на русском, украинском, казахском и английском.

## Состояние

Версия для разработки. Программа работает и пригодна для реальных деталей, но обновляется ежедневно.

- **Формат документа меняется без обратной совместимости.** Файл, сохранённый в прежней версии, может
  не открыться. Для таких файлов есть скрипт `convert_qcad.py` (см. ниже).
- **Модуль ЧПУ (CAM) не работает.** В настройках он включается галкой «Вкладка „Обработка“ (CAM)», но
  это задел на будущее: часть кода досталась от прежней версии и не поддерживается. Модуль вернётся к
  стабильной альфе.
- **Сборка под macOS не подписана Apple.** Она подписана и цела, но сертификатом, который выдала не Apple,
  поэтому при первом запуске macOS говорит, что не может проверить программу, и не открывает её. Разрешить
  нужно один раз, кнопкой «Все равно открыть» в Системных настройках -> Конфиденциальность и безопасность;
  шаги — в заметке рядом с программой.

## Возможности

**Эскиз.** Линии, дуги, окружности, эллипсы, сплайны, многоугольники, пазы, текст. Связи и размеры
решаются совместно; размеры параметрические (`w/2`, `sin(a)`). Есть вспомогательная геометрия и
проекция рёбер тела в эскиз.

**Деталь.** Выдавливание, оборот, sweep, лофт, скругление (в том числе переменного радиуса по
вершинам), фаска, оболочка, уклон, отверстия (простые, цековка, зенковка), утолщение, заплатка,
сшивка, обрезка, деление граней и тела, копирование и толкание грани, массивы линейные и круговые,
зеркало, булевы операции. Есть примитивы: параллелепипед, цилиндр, сфера, конус, тор, призма.
Резьба строится настоящим винтовым профилем со сбегами.

**Сборка.** Детали и подсборки, сопряжения (жёсткое, вращательное, ползун, цилиндрическое, плоское,
шаровое, штифт в пазу, параллельность), ограничения и приводы, степени свободы, проверка
интерференции. Эскиз строится на грани соседней детали как ассоциативная ссылка: изменение соседней
детали перестраивает зависимую.

**Обмен.** STEP (импорт и вывод), STL (импорт и вывод), DXF и SVG (импорт и вывод эскизов).
Вывести можно как весь проект, так и отдельную деталь или подсборку из дерева.

## Установка

Сборки — в разделе [Releases](../../releases). Дополнительные библиотеки не требуются: OpenCASCADE и
зависимости входят в пакет.

**Windows 10/11 x64** — `qymcad-win64.zip`. Распаковать и запустить `qymcad.exe`.

**Linux** — `qymcad-*.AppImage`, один файл. Требуется glibc 2.35 или новее: Ubuntu 22.04+,
Debian 12+, Fedora 36+, Arch.

```bash
chmod +x qymcad-*.AppImage
./qymcad-*.AppImage
```

**macOS 12+** — для Apple Silicon (M1 и новее) `qymcad-*-macos-arm64.dmg`, для Intel
`qymcad-*-macos-x86_64.dmg`. Откройте образ диска и перетащите QymCAD в «Программы». Первый запуск один раз
будет отклонён, потому что сборка не подписана Apple: нажмите «Все равно открыть» в Системных настройках ->
Конфиденциальность и безопасность. Папка `README` рядом с программой описывает это по шагам, на каждом языке программы.

## Файлы проекта

Документ сохраняется в `.qcad`. Формат меняется напрямую, без слоя совместимости; документы прежних
версий переводит отдельный скрипт:

```bash
python3 convert_qcad.py part.qcad    # переводит на месте, рядом остаётся part.qcad.bak
```

Скрипт приводит документ любой прежней версии к текущей за один проход и идемпотентен.

## Сборка из исходников

Linux — `just pkg-linux`, требуется Docker. Windows — MSVC, ядро собирается из исходников. macOS — ядро
тоже из исходников, дальше `packaging/macos/bundle.sh`. Подробности:
[`packaging/README.md`](packaging/README.md).

Ядро — OCCT 7.9.3, собранное из исходников строкой `cmake` из
[`packaging/README.md`](packaging/README.md#the-kernel). Пакет OCCT из системы может отличаться тремя важными вещами:
другая версия (программа написана и проверена на 7.9.3; на другой сборка выдаёт предупреждение);
`BUILD_RELEASE_DISABLE_EXCEPTIONS`, оставленный `ON` (собственные проверки OCCT вырезаны, и вырожденный ввод больше не
отклоняется); сигналы без перевода (`OCC_CONVERT_SIGNALS`; сбой внутри OCCT тогда закрывает программу, а не даёт отказ).
