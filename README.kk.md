## Бұл репозиторий

Бұл [QymCAD](https://github.com/QymIs-Tech/QymCAD) форкі. Графикалық бағдарлама мұнда сол. Бұл форкке бағдарламасыз бір құжатты жүргізетін API қосылған. Терминалдық бағдарлама MCP клиенті осы API-ді шақыруы үшін бар.

Бұл API — `qymcad-drive` кітапханасы. Сессия құжатты және геометриялық ядроны ұстайды. Әр өзгерістен кейін ол модельді қайта құрады және ағашты қайтарады: бөлшектер, нобайлар, амалдар таспасы, денелер, түйіспелер және еркіндік дәрежелері. Сессия арқылы бағдарлама QymCAD файлын ашады және сақтайды, сондай-ақ STEP пен STL оқиды және жазады. Координаталық жазықтықтағы нобай сығымдау, айналдыру, жол бойымен созу немесе лофт арқылы денеге айналады. Кубоидты, цилиндрді, сфераны, конусты, торды немесе призманы бірден қоюға болады. Дайын денеде сессия фаска мен дөңгелектеу жасайды, қабық пен тесік салады, денелерді біріктіреді немесе біреуін біреуінен алады, денені қатарға немесе шеңбер бойымен көбейтеді, оны шағылыстырады және тіледі. Сол дененің жақтарын еңкейтуге, жылжытуға, ығыстыруға, жоюға немесе ауыстыруға болады. Бөлшектерді жинаққа қойып, түйіспелермен байлауға болады. Өлшем өрнек бола алады, ал соңғы қадамды болдырмауға болады.

`qymcad-mcp` терминалдық бағдарламасы сол API-ді шақырады. Ол MCP тілінде стандартты енгізу мен шығару арқылы сөйлейді, және әр құрал бір әдісті орындайды. Оны MCP тілінде сөйлейтін кез келген бағдарлама іске қоса алады. Сақталған файлды көрсету керек болғанда графикалық бағдарламаның жаңа көшірмесі ашылады, ал ашық тұрған модель орнында қалады.

Лицензия — [LICENSE](LICENSE) файлындағы мәтін, GNU AGPL-3.0-or-later, QymCAD-тағымен бірдей. Бұл форк басқа шарт қоспайды. QymCAD дайын бумаларында бұл API мен терминалдық бағдарлама әлі жоқ. Екеуі де осы репозиторийде.

### IDE-ге қосу

Терминалдық бағдарламаны осы репозиторийден жинайды, OCCT 7.9.3 жолдары [Бастапқы кодтан жинау](#бастапқы-кодтан-жинау) бөліміндегідей:

```bash
cargo build --release --locked --bin qymcad-mcp
```

Бағдарлама `target/release/qymcad-mcp` ішінде жатады. IDE-де жергілікті MCP серверін қосады. Команда — осы бағдарламаға жол. IDE онымен стандартты енгізу мен шығару арқылы сөйлеседі. Сервердің мекенжайы мен порты жоқ.

```json
{
  "mcpServers": {
    "qymcad": {
      "command": "/абсолют-жол/qymcad-mcp",
      "env": {
        "LD_LIBRARY_PATH": "/абсолют-жол/occt/lib",
        "QYMCAD_GUI": "/абсолют-жол/qymcad"
      }
    }
  }
}
```

Жоғарыдағы мысал Linux үшін жазылған. `LD_LIBRARY_PATH` жиналған OCCT-тың `lib` каталогын атайды. Ядро кітапханалары бір-бірін жүктейді, және бағдарлама файлының ішіндегі жол оларға жеткіліксіз. `QYMCAD_GUI` — графикалық бағдарлама. Ол сақталған файлды көрсеткенде керек. Windows-та сол `env` өрісінде `lib` каталогын `PATH` ішіне қояды, ал `LD_LIBRARY_PATH` берілмейді.

## Бұл не

QymCAD — механикалық бөлшектер мен жинақтарға арналған жұмыс үстелі CAD-ы: корпустар, кронштейндер,
механизмдер, басып шығарылатын және фрезерленетін бұйымдар.

Эскиз созу, айналдыру немесе траектория бойымен созу арқылы денеге айналады; денеге тесіктер,
дөңгелектеулер, қабық, массивтер қосылады. Бөлшектер қосылыстар арқылы жинаққа жиналады — айналмалы,
сырғымалы, қатаң. Модель параметрлік: кез келген операциядағы өлшемді өзгертсеңіз, тізбекте одан
төменгінің бәрі, жинақты қоса, қайта құрылады.

Геометрия дәл және тұтас (B-rep), оны [OpenCASCADE](https://dev.opencascade.org/) ядросы есептейді —
FreeCAD жұмыс істейтін сол ядро. Сондықтан торлардың орнына дәл беттер, дұрыс дөңгелектеулер және
басқа CAD жүйелерімен STEP арқылы алмасу.

Интерфейс қазақ, ағылшын, орыс және украин тілдерінде қолжетімді.

## Күйі

Әзірлеу нұсқасы. Бағдарлама жұмыс істейді және нақты бөлшектерге жарамды, бірақ күн сайын жаңарып
отырады.

- **Құжат форматы кері үйлесімділіксіз өзгереді.** Ертерек нұсқада сақталған файл ашылмауы мүмкін.
  Мұндай файлдарға `convert_qcad.py` скрипті бар (төменде қараңыз).
- **СББ (CAM) модулі жұмыс істемейді.** Баптауларда «Өңдеу» (CAM) қойындысының белгішесі бар, бірақ
  оның артындағысы болашаққа арналған негіз: кодтың бір бөлігі ертеректегі нұсқадан қалған және
  қолдау көрсетілмейді. Модуль тұрақты альфада оралады.
- **macOS жинағына Apple қол қоймаған.** Жинақ қол қойылған және бүтін, бірақ сертификатты Apple бермеген,
  сондықтан алғашқы іске қосуда macOS бағдарламаны тексере алмайтынын айтып, оны ашпайды. Бір рет рұқсат
  беру керек: System Settings -> Privacy & Security ішіндегі «Open Anyway» батырмасы; қадамдар бағдарламаның
  жанындағы нұсқаулықта.

## Мүмкіндіктері

**Эскиз.** Сызықтар, доғалар, шеңберлер, эллипстер, сплайндар, көпбұрыштар, ойықтар, мәтін.
Байланыстар мен өлшемдер бірге шешіледі; өлшемдер параметрлік (`w/2`, `sin(a)`). Көмекші геометрия
және дене қырларын эскизге проекциялау бар.

**Бөлшектер.** Созу, айналдыру, траектория бойымен созу, лофт, дөңгелектеу (соның ішінде төбелерде
берілетін айнымалы радиус), фаска, қабық, еңіс, тесіктер (қарапайым, цекілеу, зенкерлеу), қалыңдату,
жамау, тігу, қию, беттер мен денені бөлу, бетті көшіру және жылжыту, сызықтық және дөңгелек
массивтер, айна, буль операциялары, және примитивтер: параллелепипед, цилиндр, сфера, конус, тор,
призма. Бұрандалар жүгірісі бар нақты бұрандалы профильмен құрылады.

**Жинақтар.** Бөлшектер мен ішкі жинақтар, қосылыстар (қатаң, айналмалы, сырғымалы, цилиндрлік,
жазық, шарлы, саусақ-ойық, параллельдік), шектер мен жетектер, еркіндік дәрежелері, қиылысуды
тексеру. Эскизді көрші бөлшектің бетіне ассоциативті сілтеме ретінде қоюға болады: көршіні
өзгертсеңіз, тәуелді бөлшек қайта құрылады.

**Алмасу.** STEP (импорт және экспорт), STL (импорт және экспорт), DXF және SVG (эскиздерді импорт
және экспорт). Бүкіл жобаны да, ағаштан таңдалған жеке бөлшекті не ішкі жинақты да жазуға болады.

## Орнату

Жинақтар [Releases](../../releases) бөлімінде. Қосымша кітапханалар қажет емес: OpenCASCADE және
тәуелділіктер пакеттің ішінде.

**Windows 10/11 x64** — `qymcad-win64.zip`. Кез келген жерге ашып, `qymcad.exe` іске қосыңыз.

**Linux** — `qymcad-*.AppImage`, бір файл. glibc 2.35 не жаңарағы керек: Ubuntu 22.04+, Debian 12+,
Fedora 36+, Arch.

```bash
chmod +x qymcad-*.AppImage
./qymcad-*.AppImage
```

**macOS 12+** — Apple Silicon (M1 және кейінгілері) үшін `qymcad-*-macos-arm64.dmg`, Intel үшін
`qymcad-*-macos-x86_64.dmg`. Диск бейнесін ашып, QymCAD-ты «Бағдарламалар» қалтасына сүйреңіз. Жинаққа Apple
қол қоймағандықтан, алғашқы іске қосу бір рет қабылданбайды: System Settings -> Privacy & Security ішінде
«Open Anyway» батырмасын басыңыз. Бағдарламаның жанындағы `ОҚЫҢЫЗ.txt` мұны қадам бойынша сипаттайды.

## Анықтама

Кірістірілген анықтама **F1** пернесімен ашылады. Суреттері бар мақалалар [`docs/help`](docs/help)
қалтасында.

## Жоба файлдары

Құжат `.qcad` ретінде сақталады. Формат үйлесімділік қабатынсыз тікелей өзгереді; ертерек
нұсқалардың құжаттары бөлек скриптпен жаңартылады:

```bash
python3 convert_qcad.py part.qcad    # файлды орнында түрлендіреді, жанына part.qcad.bak қалдырады
```

Скрипт құжатты кез келген ертерек нұсқадан бір өтуде ағымдағысына жеткізеді және идемпотентті.
